# Платёжная инфраструктура: карточки провайдеров

Дата проверки: **10.10.2026**. Ваша ситуация: гражданин Таджикистана, фактически находитесь в Москве, основание пребывания — патент, без ИП/юрлица.

Статусы: **ПОДТВЕРЖДЕНО** · **ТРЕБУЕТ ПРОВЕРКИ** · **НЕ ПОДХОДИТ**.

> ⚠️ Главный нерешённый вопрос — **юридический, а не технический**: патент разрешает трудовую деятельность по найму. Регулярный доход от продажи собственного продукта — это предпринимательская деятельность. Самозанятость (НПД) для граждан Таджикистана недоступна, ИП в РФ требует РВП/ВНЖ. Варианты для обсуждения с юристом/налоговым консультантом: (1) регистрация ИП в Таджикистане и законный порядок получения дохода; (2) получение РВП → ИП в РФ; (3) иной законный вариант, который подтвердит специалист. **До консультации не начинайте регулярные продажи.** Всё остальное (продукт, сайт, тестирование, маркетинговые материалы) от этого не зависит и готово.

## 5. Прямая продажа по счёту (резервный вариант)

Код поддерживает ручную выдачу лицензий: `npm run issue-license -- buyer@example.com invoice-001`. Если клиент (например, бухгалтерская фирма) хочет заплатить по счёту, это можно сделать через тот же lava.top (продукт с ценой «по запросу через API») или иным законным способом после решения вопроса со статусом. **ТРЕБУЕТ ПРОВЕРКИ** того же юридического вопроса.

## Почему выбрана именно такая схема

- Покупатель платит картой/PayPal в USD/EUR на платёжной странице lava.top.
- Наш сервер **никогда не верит браузеру**: ключ выдаётся только после того, как сервер сам запросил у lava.top статус заказа и получил `COMPLETED`.
- Ключ подписан ECDSA P-256 закрытым ключом, который хранится только в секретах хостинга; браузер проверяет подпись открытым ключом.
- Повторные вебхуки lava.top (до 20 попыток) обрабатываются один раз (идемпотентность по `event_id`/`contractId` в KV).
- Возвраты и чарджбэки приходят вам уведомлением в Telegram.
