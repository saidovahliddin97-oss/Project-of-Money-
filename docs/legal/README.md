# Legal documents — what is live and what still needs owner input

They describe the real behaviour of LocalLedger and IIF Kit. They are templates written for this product, **not** a legal opinion.

Still to be confirmed by the owner (with a lawyer if possible) before scaling — deliberately not published with invented values:

- [GOVERNING LAW] and dispute venue.
