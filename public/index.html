Questions

Is my statement really not uploaded?

Yes. The converter is a web page that runs JavaScript in your browser. The PDF is read with the open-source pdf.js library on your device. The only network requests the app makes are anonymous usage counters (for example "a file was converted" — never the file, its contents or your name) and, if you buy, the checkout.

Which banks are supported?

LocalLedger does not use per-bank templates. It reads the layout of the page — dates, descriptions, amount and balance columns — so it works with most text-based statements from banks and card issuers worldwide. Try your own file for free before paying: the preview shows exactly what you will get.

Does it work with scanned statements?

Not yet. The PDF needs a text layer (if you can select text in it, it will work). Statements downloaded from online banking almost always have one.

How do I import the result into QuickBooks Online or Xero?

Choose the "QuickBooks Online (CSV)" or "Xero (CSV)" export and follow our step-by-step guides for QuickBooks Online and Xero.

How does the license work?

After payment you get a license key tied to your email. It unlocks Pro in your browser; you can paste it on any computer you use. No account or password needed.

What if it doesn't work for my statement?

You can test every file for free before buying. If you buy and it still doesn't work for you, ask for a refund within 14 days.
