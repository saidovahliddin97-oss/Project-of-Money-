    How to import the IIF file into QuickBooks Desktop

    1. Back up your company file first (File → Back Up Company). IIF imports cannot be undone automatically.
    2. Check that the bank/card account and the accounts in your rules exist with exactly these names.
    3. In QuickBooks Desktop choose File → Utilities → Import → IIF Files, select the downloaded file and follow the prompts.
    4. Open the bank register and review the imported checks and deposits.

    The file follows Intuit's published IIF transaction format (tab-separated TRNS/SPL/ENDTRNS records). Intuit does not provide support for creating IIF files; test with a small file first.
