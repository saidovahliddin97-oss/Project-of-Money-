Convert CSV to QIF for Quicken, GnuCash, Moneydance and other finance apps

Updated 2026-10-10

QIF (Quicken Interchange Format) is an old, plain-text format for transactions. It is still useful because many personal-finance programs import it: GnuCash, Moneydance, Banktivity, HomeBank and older or specific versions of Quicken among them. Check your program's import documentation for which account types accept QIF.

What a QIF file looks like

!Type:Bank
D01/05/2026
T-4.50
PCOFFEE HOUSE
MCOFFEE HOUSE #123 SEATTLE WA
^

D is the date, T the signed amount, P the payee, M a memo, and ^ ends each transaction. Credit card files start with !Type:CCard.

Converting a CSV or PDF statement to QIF

  1. Open the converter and drop your bank CSV export or PDF statement.
  2. For CSV files, LocalLedger maps the Date, Description, Amount (or Debit/Credit) columns automatically. Check the preview.
  3. Choose QIF and download. Card statements are written as CCard, bank statements as Bank.

Common QIF problems

  • Day/month swapped: QIF has no date-format header. LocalLedger writes MM/DD/YYYY by default; choose DD/MM/YYYY under Options if your program expects that.
  • Duplicates: QIF has no transaction ids, so importing the same file twice usually duplicates rows. Prefer OFX if your program supports it.
  • Wrong account type: some programs only accept QIF into specific account types or into a new file — check their help pages.
