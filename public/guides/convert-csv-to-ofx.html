Convert a bank CSV or PDF statement to OFX

Updated 2026-10-10

OFX (Open Financial Exchange) is the format banks use for "download to accounting software". Unlike CSV and QIF, every transaction in an OFX file has a unique id (FITID), so finance apps can skip transactions they have already imported.

Which apps import OFX?

GnuCash, Moneydance, YNAB (file import), Banktivity, HomeBank, Microsoft Money Plus Sunset, Xero and many others accept OFX. Quicken expects its own variant (QFX) for some import paths, so QIF or CSV may be the better choice there.

How to create an OFX file

  1. Drop your CSV export or PDF statement into the converter.
  2. Under Options, set the currency (for example USD, EUR, GBP) and optionally an account number so your app links the file to the right account.
  3. Review the transactions, then choose OFX and download.

What LocalLedger puts in the file

  • OFX 1.0.2 (SGML), the version supported most widely.
  • A stable FITID per transaction, built from date, amount and description. Re-exporting the same statement produces the same ids, so a careful app will not duplicate them.
  • A bank-account or credit-card statement block depending on the statement type.
  • The last running balance from the statement as the ledger balance, when available.
