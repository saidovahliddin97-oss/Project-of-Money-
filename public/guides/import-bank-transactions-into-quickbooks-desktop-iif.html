Import bank transactions into QuickBooks Desktop with an IIF file

Updated 2026-10-10

QuickBooks Desktop (Pro, Premier, Enterprise) does not have a simple "import this bank CSV" command the way a spreadsheet does. The usual supported route is a bank connection or a Web Connect (.QBO) file from your bank. When neither is available, or a feed is broken, many bookkeepers fall back to an IIF file: a tab-separated text file that QuickBooks Desktop can import through File → Utilities → Import → IIF Files. Intuit does not officially support creating IIF files by hand, so treat the import as something you test first.

What an IIF file contains

An IIF file is plain text with header rows that start with !, followed by data rows. A bank transaction is written as one TRNS line (the bank account side) and one or more SPL lines (the account it is categorized to), closed by ENDTRNS. The SPL amounts must add up to the negative of the TRNS amount, or QuickBooks rejects the transaction.

!TRNS	TRNSTYPE	DATE	ACCNT	NAME	AMOUNT	MEMO
!SPL	TRNSTYPE	DATE	ACCNT	NAME	AMOUNT	MEMO
!ENDTRNS
TRNS	CHECK	01/05/2026	Checking	Shell	-45.00	SHELL OIL 1234
SPL	CHECK	01/05/2026	Automobile:Fuel	Shell	45.00	SHELL OIL 1234
ENDTRNS

Step by step

  1. Get the transactions out of the bank. Download the CSV export, or keep the PDF statement if the bank offers nothing else. Text-based PDFs work; scanned images do not.
  2. Open IIF Kit in your browser and drop the file in. The processing happens on your computer; the statement is not uploaded.
  3. Check the preview. Confirm the first and last dates, the sign of the amounts (money out negative), and that the row count matches the statement. If the day and month look swapped, change the date order before exporting.
  4. Map the accounts with rules. Write one rule per line in the form keyword => Account, for example shell => Automobile:Fuel or payroll => Payroll Expenses. Rows that match a rule get that account; you can edit any remaining row by hand.
  5. Download the .IIF file.
  6. Back up your company file in QuickBooks before importing anything.
  7. Import. In QuickBooks Desktop choose File → Utilities → Import → IIF Files and select the file.

Test before you trust it

  • Account names must match your chart of accounts exactly, including sub-account paths such as Automobile:Fuel. A typo can create an unwanted account or fail the row. Compare your rule names with the chart of accounts first.
  • Start with a handful of rows in a test company file, then look at the register. Only then import a full month into the live file.
  • Reconcile afterward. The register balance after import should agree with the statement's closing balance. See how to check converted transactions.
  • Avoid duplicates. If part of the period was already entered or came through a bank feed, remove those rows from the CSV before converting. Importing the same file twice enters everything twice.

Bank accounts versus credit cards

For a bank account, withdrawals are naturally written as checks and deposits as deposits. For a credit card account, IIF Kit writes journal entries instead, so the card account and the expense accounts both move correctly.

Limits to know about

  • IIF Kit handles bank and card transactions. It does not import invoices, bills or lists such as customers and items.
  • Scanned (image-only) PDF statements are not supported.
  • QuickBooks Online does not use IIF. For Online, convert to a bank-upload format instead: see importing a statement into QuickBooks Online.
  • The free preview exports up to 15 rows; the full version is a one-time purchase.

If you only need a clean CSV to review or send to a client, converting a PDF statement to CSV is the first step, and IIF Kit then turns that CSV into the .IIF file.
