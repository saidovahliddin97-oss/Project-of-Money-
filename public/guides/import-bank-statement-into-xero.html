How to import a bank statement into Xero from a PDF or CSV

Updated 2026-10-10

Xero lets you import statement lines manually when there is no bank feed, the feed started late, or a period is missing. Xero accepts CSV, OFX, QIF and QBO files. CSV is the most predictable.

The CSV layout for Xero

Xero's statement template uses these columns: *Date, *Amount, Payee, Description, Reference (plus optional coding columns). Columns marked with * are required. Money out is negative. The date format must match your organisation's regional settings — for most regions outside the US that is DD/MM/YYYY.

LocalLedger's Xero (CSV) export produces exactly these columns, with a payee guessed from the description.

Step 1 — Convert the statement

  1. Drop the statement into the converter.
  2. Confirm the balances reconcile; fix highlighted rows.
  3. Under Options, set the CSV date format to match your Xero organisation.
  4. Export Xero (CSV).

Step 2 — Import into Xero

  1. In Xero, open Accounting → Bank accounts.
  2. Find the account, open Manage account and choose Import a statement.
  3. Browse to the CSV file and click Import.
  4. Assign the columns if Xero asks (Date, Amount, Payee, Description, Reference) and save.
  5. The lines appear in the bank account ready to reconcile.

Tips

  • Xero warns about lines it has already imported, but it is still safest to import only the missing period.
  • If a statement line is wrong after import, you can delete imported statement lines from the account's statement view and import a corrected file.
  • Keep one file per bank account. Do not mix two accounts in one import.
