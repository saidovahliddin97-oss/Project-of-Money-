# EDITH — ваш ИИ-помощник в стиле Джарвиса

Локальное приложение, которое запускается у вас на Mac. Кинематографичный HUD-интерфейс
(кольца реактора, голубое свечение), общение **голосом и текстом**, Эдит **сама пишет
первой** (напоминает о паузах, предлагает помощь) и умеет **управлять вашим Mac** —
открывать программы, печатать, кликать, делать скриншоты, выполнять команды — всегда
с вашим подтверждением для опасных действий.

«Мозг» — на выбор, **бесплатные** варианты. По умолчанию — локальная модель
через Ollama (ничего не платите, ключ не нужен, данные не уходят с Mac).

---

## Быстрый старт (бесплатно, по умолчанию — локальный Ollama)

1. Нужен **Node.js 20+** (проверьте: `node -v`).
2. Установите **Ollama** с <https://ollama.com> (обычное приложение).
3. Двойной клик по **`edith/Запустить-Эдит.command`** — он сам создаст
   настройки, при первом запуске скачает модель и откроет Эдит в браузере.
   (Вручную: `npm run edith`.)
4. Откройте в **Chrome** <http://localhost:4330>. Для голоса нужен Chrome.

### Облачные бесплатные альтернативы (если Mac слабоват для локальной модели)
Откройте `edith/.env` и переключите провайдера:
- **Groq** — ключ бесплатно на <https://console.groq.com> (без карты), очень быстро.
- **Google Gemini** — ключ на <https://aistudio.google.com/app/apikey> (без карты).
- **OpenRouter** — есть бесплатные модели (`:free`).

Все варианты и строки для вставки — в `edith/.env.example`.

## Что умеет

| Возможность | Как работает |
|---|---|
| **Голос** | Микрофон в интерфейсе — говорите, Эдит распознаёт речь (ru-RU) и отвечает вслух. |
| **Текст** | Обычный чат, ответы печатаются в реальном времени. |
| **Инициатива** | Эдит сама напоминает сделать паузу после ~1.5 ч работы и предлагает помощь в тишине. Тумблер «инициатива» выключает это. |
| **Поиск в интернете** | Бесплатный веб-поиск через DuckDuckGo (без ключа). |
| **Управление Mac** | Открыть приложение/ссылку, уведомления, снимок экрана — сразу. Печать, клики, горячие клавиши, AppleScript, команды терминала — **после вашего подтверждения** в интерфейсе. |
| **Окна внутри HUD** | Эдит открывает сайты, заметки и картинки киношными окнами прямо в интерфейсе (можно перетаскивать). Если сайт запрещает встраивание — кнопка «открыть в браузере». |
| **Эко-режим** | Тумблер «эко» убирает тяжёлые анимации ради батареи. Анимации сами встают на паузу, когда вкладка скрыта, и эко включается автоматически при низком заряде. |

### Точные клики и печать
Базовые действия работают на «голом» macOS (`osascript`, `open`, `screencapture`, `say`).
Для точных кликов мышью по координатам поставьте `cliclick`:
```bash
brew install cliclick
```
Также для управления вводом включите для вашего терминала/Node доступ в
**Системные настройки → Конфиденциальность → Универсальный доступ** и **Запись экрана**.

## Безопасность

- С локальным Ollama данные **не покидают Mac вообще** — ни ключей, ни облака.
  С облачными провайдерами наружу уходят только ваши запросы к их API.
- Опасные действия (`type_text`, `key`, `click`, `applescript`, `shell`) **никогда** не
  выполняются без вашего явного «Разрешить» в интерфейсе.
- Это инструмент для управления **вашим собственным** компьютером.
- Произвольные команды терминала и AppleScript **отключены по умолчанию** — это
  слишком мощный доступ. Включаются осознанно через `EDITH_ALLOW_SHELL=1`.
- Сервер отвечает только на запросы со своей же страницы (localhost); сторонний
  сайт не может достучаться до моста через ваш браузер.

## Про VPN и регионы

- **Ollama (локально)** — VPN не нужен вообще, работает офлайн.
- **Groq / Gemini / OpenRouter** — это иностранные сервисы; из некоторых регионов
  к ним нужен VPN. Веб-поиск (DuckDuckGo) тоже может требовать VPN.

## Файлы

```
edith/
  server.mjs        локальный сервер (статика + API + проактивный канал)
  lib/llm.mjs       универсальный клиент к бесплатным моделям (OpenAI-совместимый)
  lib/search.mjs    бесплатный веб-поиск (DuckDuckGo)
  lib/computer.mjs  мост управления macOS (с классификацией действий)
  lib/proactive.mjs движок инициативы (напоминания/проверки)
  public/           HUD-интерфейс (index.html, edith.css, edith.js)
  .env.example      шаблон настроек
```
