# LocalLedger

**Конвертер банковских выписок, который не загружает файлы на сервер.**
PDF/CSV-выписка → Excel, CSV, QuickBooks Online CSV, Xero CSV, QIF, OFX. Всё распознавание выполняется в браузере пользователя.

- Аудитория: бухгалтеры и bookkeeping-фирмы, владельцы малого бизнеса, пользователи QuickBooks/Xero/Quicken/GnuCash/YNAB (США, Великобритания, ЕС, Австралия).
- Проблема: транзакции из PDF-выписок перепечатывают вручную или загружают конфиденциальные данные на чужие серверы; облачные конвертеры стоят $20–$360 в месяц.
- Монетизация: бесплатный просмотр + экспорт до 15 строк; **Pro — $29 разово** через lava.top; ключ лицензии выдаётся автоматически после подтверждения оплаты.

## Возможности (реализовано и протестировано)

| Функция | Статус |
|---|---|
| Распознавание текстовых PDF: даты (MM/DD, DD/MM, ISO, «31 Jan», без года), суммы (1,234.56 / 1.234,56 / (12.00) / 12.00 CR/DR), колонки Debit/Credit/Balance, переносы описаний, дата один раз на день (UK), выписки по кредитным картам | ✅ |
| Знак суммы по колонке, по явной метке или по движению остатка | ✅ |
| Сверка с начальным/конечным остатком выписки | ✅ |
| Импорт CSV с автоопределением разделителя, колонок, формата даты и десятичного разделителя | ✅ |
| PDF с паролем (пароль не покидает браузер) | ✅ (код), ручная проверка не проводилась |
| Таблица с редактированием, сменой знака, удалением/добавлением строк, сортировкой, удалением дубликатов | ✅ |
| Экспорт: CSV (с BOM и защитой от формул), Excel .xlsx (настоящие даты и числа), QuickBooks Online CSV, Xero CSV, QIF (Bank/CCard), OFX 1.0.2 (стабильные FITID) | ✅ |
| Оплата через lava.top: создание инвойса, проверка статуса на сервере, выдача подписанного ключа (ECDSA P-256), активация ключа на другом устройстве | ✅ на имитации API lava.top; **с реальным lava.top не проверено** (нужны ваши ключи) |
| Вебхуки lava.top: авторизация, идемпотентность, уведомления в Telegram о продажах/ошибках/возвратах/чарджбэках | ✅ модульные тесты |
| Анонимные счётчики воронки + `/api/stats` | ✅ |
| Лендинг, тарифы, FAQ, 8 SEO-гайдов, sitemap, политика конфиденциальности, условия и возвраты, мобильная вёрстка, тёмная тема | ✅ |
| OCR сканов | ❌ не реализовано (запланировано, если спрос подтвердится) |

## Структура

```
public/                    статический сайт (выходная папка для хостинга)
  index.html               лендинг + тарифы + FAQ
  app.html                 конвертер
  success.html, cancel.html  возврат после оплаты
  setup.html               генерация ключа подписи (для владельца, noindex)
  guides/                  8 SEO-гайдов (генерируются scripts/build-guides.mjs)
  assets/js/core/          ядро: amounts, dates, csv, pdf-layout, pdf-extract,
                           statement-parser, csv-import, exporters, xlsx, license
  assets/js/app.js         UI конвертера
  assets/js/pro.js         лицензия, оплата
  assets/vendor/pdfjs/     pdf.js 6.3.289 (Apache-2.0)
server/                    API: handlers.js (checkout, claim, webhook, events, stats, pubkey), lava.js
functions/api/[[path]].js  адаптер Cloudflare Pages Functions
api/router.js, vercel.json адаптер Vercel (альтернатива)
scripts/                   деплой на Cloudflare (deploy-cloudflare.mjs), dev-сервер, гайды, ключи, ручная выдача лицензий, офферы lava.top
tests/unit/                25 модульных тестов (node:test)
tests/e2e/run-e2e.mjs      15 сквозных проверок в Chromium
tests/fixtures/make-pdfs.mjs  генератор тестовых выписок (US, UK, карта, EU, скан)
```

## Локальный запуск

```bash
npm install
npm test
npm run test:e2e   # нужен Playwright + Chromium
npm run dev        # http://localhost:8787
```

Переменные окружения — в [.env.example](.env.example). Секреты не хранятся в репозитории.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | какие интеграции настроены (без секретов) |
| GET | `/api/pubkey` | открытый ключ проверки лицензий |
| POST | `/api/checkout` | `{email, currency, method}` → инвойс lava.top → `{paymentUrl}` |
| POST | `/api/claim` | `{invoiceId}` → сервер проверяет статус в lava.top → ключ лицензии |
| POST | `/api/webhook/lava` | вебхуки lava.top (X-Api-Key или Basic Auth) |
| POST | `/api/event` | анонимный счётчик события |
| GET | `/api/stats?token=` | счётчики по дням |
| POST | `/api/admin/issue` | ручная выдача ключа (Bearer ADMIN_TOKEN) |

## Известные ограничения

- Сканы (PDF без текстового слоя) не поддерживаются — пользователь видит понятную ошибку.
- Распознавание эвристическое: протестировано на 4 синтетических макетах (US, UK, кредитная карта, EU). На реальных выписках отдельных банков возможны ошибки — для этого есть таблица с правкой и проверка сверки.
- Проверка лицензии выполняется в браузере: технически грамотный пользователь может её обойти. Для продукта за $29 это осознанный компромисс (нет аккаунтов и серверного хранения данных).
- Отзыв лицензий после возврата не реализован (возвраты фиксируются в KV и приходят уведомлением).
