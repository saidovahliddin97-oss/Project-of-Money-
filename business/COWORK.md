# Связь с Cowork (Mac владельца)

Облачная сессия Claude Code и Cowork на Mac напрямую не видят друг друга. Поэтому связь идёт через этот файл в ветке `claude/peaceful-dijkstra-pxl0xc`.
- **Cowork** выполняет задачи со статусом `новая`, записывает результат в раздел «Результаты» и коммитит через веб-редактор GitHub.
- **Облачная сессия** забирает результаты, продолжает работу и добавляет новые задачи.

Правила для Cowork:
1. Брать задачи сверху вниз, только со статусом `новая`. После выполнения ставить `сделано` или `нужен владелец: <почему>`.
2. Без отдельного «да» владельца не делать: оплаты, рекламные бюджеты, удаление чего-либо, публикации от имени владельца, которых нет в задаче.
3. Секреты (пароли, коды, токены, ссылки с `#` после `unlock.html`) в этот файл не писать — репозиторий публичный.
4. Если нужен вход, капча или код из SMS/2FA — пропустить задачу, статус `нужен владелец`.
